# 18 — ทะเบียนแหล่งอ้างอิงทางกฎหมายและข้อมูลภายนอก (Legal & External Sources Register)

> สถานะ: Phase 0 · วันที่ค้นข้อมูล: 23–26 พฤศจิกายน 2569
> **ข้อจำกัดสำคัญที่ต้องอ่านก่อน:** ไม่สามารถเปิดเว็บไซต์ `rd.go.th` โดยตรงได้ใน Phase 0 (เครือข่ายของสภาพแวดล้อมปฏิเสธโฮสต์ และคำขอเพิ่มสิทธิ์ถูกผู้ใช้ปฏิเสธ) ข้อมูลทั้งหมดในตารางด้านล่างจึงมาจาก **ข้อความสรุปที่เครื่องมือค้นหาดึงมาจากหน้าเว็บของกรมสรรพากร** — ไม่ใช่การอ่านต้นฉบับครบถ้วน ข้อความที่อ้างเป็น "ถ้อยคำ" ในเอกสารอื่นอาจไม่ตรงตัวอักษรกับต้นฉบับ
> ผู้ตรวจ (ผู้พัฒนา/ผู้เชี่ยวชาญภาษี) ต้องเปิดต้นฉบับทุกแถวที่ระดับ V1 แล้วกรอกวันที่ตรวจในคอลัมน์สุดท้าย (Checklist CL-01 ใน `06_TAX_SPECIFICATION.md` §14)

| ระดับ | ความหมาย |
|---|---|
| **V1** | พบเนื้อหาในหน้าเว็บ/เอกสารของ rd.go.th ผ่านผลค้นหา (ยังไม่อ่านต้นฉบับ ยังไม่ยืนยันว่าเป็นฉบับปัจจุบัน) |
| **V2** | พบจากสื่อ/บุคคลที่สาม ยังไม่พบในแหล่งทางการ |
| **V0** | ไม่พบหลักฐาน — เป็นข้อเสนอเชิงออกแบบ |
