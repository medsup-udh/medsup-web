## ข้อจำกัดของ Wireframe ชุดนี้

- เป็นภาพระดับกลาง (mid-fidelity) เพื่อตรวจโครงหน้าและขั้นตอน ไม่ใช่ดีไซน์สุดท้าย — สี ตัวอักษร ระยะ ตาม `07_UI_UX_SPECIFICATION.md` §3 แต่รายละเอียดภาพอาจปรับใน Phase 1
- หน้าจอรายงาน (S12) แสดงตัวอย่าง 1 จาก 9 รายงาน; รายงานที่เหลือใช้โครงเดียวกัน (ตัวกรอง → ตาราง → ยอดรวม → Export)
- มือถือทำภาพ 5 หน้าที่ใช้บ่อย; หน้าอื่นใช้กฎเดียวกัน (ตารางเป็นการ์ด ปุ่มหลักติดขอบล่าง)
- แถบปุ่มด้านล่างของหน้าจัดทำเอกสาร/รับชำระ ในระบบจริงจะติดขอบจอ (sticky) แต่ในภาพ desktop วางไว้ท้ายหน้าเพื่อให้เห็นครบ
- ตัวเลือกที่รอตัดสินใจ (D-xx ใน `../15_OPEN_ISSUES.md`) แสดงเป็นค่าเริ่มต้นที่เสนอ เช่น ปีปฏิทิน ค.ศ. ใน S13
