# 16 — สรุปผล Phase 0 สำหรับผู้ว่าจ้าง

> BizFlow — ระบบจัดทำเอกสารการขายและรับชำระเงิน · Phase 0: Planning & System Design
> สถานะ: **ส่งมอบเอกสารออกแบบครบแล้ว — รอผู้ว่าจ้างตรวจและตอบคำถาม · ยังสรุปว่า "ผ่าน" ไม่ได้** (ตามเงื่อนไขท้าย PART 14)
> **อัปเดต 26 พ.ย. 2569:** ผู้ว่าจ้างแจ้งกรณีใช้งานหลัก (ขายหน่วยงานรัฐเงินเชื่อ หักภาษี 1% ไม่ต้องมีใบส่งของ ใช้บนมือถือ) จึงเพิ่มข้อเสนอรุ่นแรกแบบง่าย **BizFlow Lite** ใน `19_LITE_MVP_SCOPE.md` (ภาพหน้าจอมือถือใน `19_LITE_WIREFRAMES/`) — รอ D-24 · ตัวเลขในเอกสารนี้ (18–22 สัปดาห์ ฯลฯ) เป็นของแผนเต็ม; รุ่น Lite ประมาณ 12–16 สัปดาห์
> ผู้ช่วยหยุดอยู่ที่ Phase 0 — **ไม่มีการเขียนโค้ดระบบ ไม่มีการสร้างฐานข้อมูลจริง ไม่ได้แก้ไฟล์เดิมของ repository** · ห้ามเริ่ม Phase 1 จนกว่าจะได้รับการอนุมัติอย่างชัดเจน

## 1. สรุปใน 1 นาที

| คำถาม | คำตอบ |
|---|---|
| ทำอะไรเสร็จ | เอกสารออกแบบ 16 ฉบับตาม PART 13 + ทะเบียนแหล่งกฎหมาย + รายงานตรวจความสอดคล้อง รวม 13 หน้าจอ Wireframe และตัวอย่างเอกสาร A4 ทั้ง 4 ประเภทเป็น PDF/ภาพ |
| ระบบที่เสนอ | เว็บแอป TypeScript/Next.js + PostgreSQL บนเซิร์ฟเวอร์สิงคโปร์ + สำรองข้อมูลเข้ารหัสไปอีกผู้ให้บริการหนึ่ง (Stack B) — ค่าบริการประมาณ **1,400 บาท/เดือน (≈ 17,300 บาท/ปี)** ยังไม่ยืนยันราคาทางการ |
| ใช้เวลาพัฒนา | ประมาณ **18–22 สัปดาห์** สำหรับนักพัฒนา 1 คน (±40%) ไม่รวมเวลารอคำตอบ — 4 Phase |
| ผ่านหรือยัง | **ยัง** — มีประเด็นที่ต้องตอบก่อนเริ่ม Phase 1 อยู่ 7 ข้อ และข้อกฎหมายภาษียังไม่ได้อ่านจากต้นฉบับ |
| สิ่งที่ผู้ว่าจ้างต้องทำก่อน | ตอบ 4 การตัดสินใจแรก (D-01…D-04) และให้ผู้เชี่ยวชาญภาษีตอบ OI-T07, OI-T13 — แล้วสั่ง "อนุมัติ Phase 0" |

### 2.4 ความเสี่ยงสำคัญ (จาก 15 รายการใน `15_OPEN_ISSUES.md` §C)

1. **RISK-01** ข้อกำหนดภาษีผิด/ไม่ทันสมัย — สูง — ต้องตรวจต้นฉบับและให้ผู้เชี่ยวชาญตรวจ
2. **RISK-04** กู้คืนข้อมูลไม่ได้จริง — ผลกระทบสูงมาก — แผนสำรอง 3-2-1 + ทดสอบ restore รายสัปดาห์ + ซ้อมรายไตรมาส
3. **RISK-05** บัญชีเดียวถูกยึด — แนะนำ MFA บังคับ (D-10)
4. **RISK-02/03** เลขที่เอกสาร/ตัวเลขเงินคลาดเคลื่อน — ออกแบบให้ฐานข้อมูลบังคับ + ทดสอบพร้อมกัน + property tests
5. **RISK-11** อัตรา VAT 7% มีกำหนดถึง 30 ก.ย. 2570 (ตามข่าว ยังไม่ยืนยัน) — ระบบเก็บอัตราตามช่วงวันที่ + เตือนล่วงหน้า 60 วัน
