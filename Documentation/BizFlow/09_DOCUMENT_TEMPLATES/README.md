## แผนผังตำแหน่งข้อมูล (ทุกเอกสาร)

```
┌──────────────────────────────────────────────────────────────┐
│ [โลโก้] ชื่อบริษัท (ไทย)                   [ต้นฉบับ/สำเนา]   │
│         ชื่ออังกฤษ                          ชื่อเอกสาร (ใหญ่) │
│         ที่อยู่สถานประกอบการที่ออก          เลขที่ · วันที่   │
│         เลขผู้เสียภาษี · สำนักงานใหญ่/สาขา  ครบกำหนด/อ้างอิง │
├──────────────────────────────────────────────────────────────┤
│ ผู้ซื้อ: ชื่อ · ที่อยู่ · เลขผู้เสียภาษี · สำนักงานใหญ่/สาขา  │
├──────────────────────────────────────────────────────────────┤
│ # │ รหัส │ รายการ │ จำนวน │ หน่วย │ ราคา │ ส่วนลด │ จำนวนเงิน │
│ …                                                            │
├────────────────────────────────┬─────────────────────────────┤
│ จำนวนเงินตัวอักษร              │ รวมเป็นเงิน                 │
│ การชำระเงิน / บัญชีธนาคาร      │ หักส่วนลดท้ายเอกสาร         │
│                                │ มูลค่าก่อนภาษี / VAT 7%     │
│                                │ จำนวนเงินรวมทั้งสิ้น        │
├────────────────────────────────┴─────────────────────────────┤
│ [ลายเซ็นผู้รับเงิน/ผู้ส่ง]              [ลายเซ็นผู้ซื้อ/ผู้รับ]  │
└──────────────────────────────────────────────────────────────┘
```

## ความต่างตามประเภทเอกสาร

| ส่วน | QT | DN | INV | RC |
|---|---|---|---|---|
| ช่องข้อมูลหัวขวา | ยืนราคาถึง, เครดิต | อ้างอิง QT, PO | ครบกำหนด, อ้างอิง DN/PO, หน้า x/y | อ้างอิงการรับชำระ |
| กล่องผู้ซื้อ | "เสนอราคาให้" | "ส่งสินค้าให้" + กล่องสถานที่จัดส่ง | "ผู้ซื้อ / ลูกค้า" + เลขผู้เสียภาษี + สาขา | "ได้รับเงินจาก" |
| ตาราง | รายการสินค้า | รายการสินค้า | รายการสินค้า | ใบกำกับภาษีที่ชำระ (ยอดใบ / ก่อนหน้า / ครั้งนี้ / คงเหลือ) |
| สรุปยอด | ✓ | ✓ (ตั้งค่าซ่อนราคาได้ — เสนอ) | ✓ + VAT แยกบรรทัด | ยอดตัดหนี้ − WHT − ค่าธรรมเนียม = เงินที่ได้รับ |
| ท้ายเอกสาร | เงื่อนไข | หมายเหตุ "ไม่ใช่ใบกำกับภาษี" | การชำระเงิน + บัญชีธนาคาร | วิธีรับชำระ + ข้อความ "รวม VAT แล้วตามใบกำกับภาษีเลขที่ …" |
| ลายเซ็น | ผู้เสนอราคา / ลูกค้า | ผู้ส่ง / ผู้รับ | ผู้มีอำนาจลงนาม / ผู้ซื้อ | ผู้รับเงิน / ผู้จ่ายเงิน |
