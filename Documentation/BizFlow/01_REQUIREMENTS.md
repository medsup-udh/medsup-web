# 01 — ข้อกำหนดระบบ (Requirements)

> โครงการ: BizFlow — ระบบจัดทำเอกสารการขายและรับชำระเงิน
> สถานะ: Phase 0 — ร่างเพื่อตรวจรับ (ยังไม่อนุมัติ)
> อ้างอิง: Master Specification v1.0 (PART 1–15)

> **อัปเดต 26 พ.ย. 2569:** มีข้อเสนอรุ่นแรกแบบย่อ (BizFlow Lite) ที่เลื่อนบางข้อกำหนดไปรุ่นถัดไป ดู `19_LITE_MVP_SCOPE.md` §4 — ข้อกำหนดในเอกสารนี้ **ยังไม่ถูกแก้** จนกว่าผู้ว่าจ้างอนุมัติ D-24

## 1. สรุปผลการวิเคราะห์

| หัวข้อ | สรุป |
|---|---|
| ผู้ใช้ | ผู้ใช้คนเดียว (Owner) ใช้งานผ่าน Web Browser บน Desktop และมือถือ |
| กิจการ | บริษัทจำกัด จดทะเบียนภาษีมูลค่าเพิ่ม (VAT) |
| เอกสารหลัก | ใบเสนอราคา (QT), ใบส่งของ (DN), ใบกำกับภาษีเต็มรูป (INV), ใบเสร็จรับเงิน (RC) |
| แกนกลางของระบบ | Tax Engine กลาง, Running Number ที่ไม่ซ้ำ, Snapshot ข้อมูล ณ วันออกเอกสาร, Audit Trail, Payment Allocation |
| สิ่งที่ไม่ทำ | คลังสินค้า/สต็อก, จัดซื้อ, บัญชีแยกประเภท, เงินเดือน, ระบบบัญชีเต็มรูป |

ระดับความสำคัญใช้หลัก MoSCoW: **M** = Must, **S** = Should, **C** = Could
คอลัมน์ "ที่มา" อ้างถึง PART ใน Master Specification; รายการที่มีป้าย **(เสนอเพิ่ม)** คือข้อเสนอของผู้วิเคราะห์ ซึ่งต้องได้รับอนุมัติก่อน (ดู `15_OPEN_ISSUES.md`)

## 2. ผู้ใช้และบทบาท
