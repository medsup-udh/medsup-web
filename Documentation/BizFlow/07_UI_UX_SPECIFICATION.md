# 07 — แนวทางออกแบบ UI/UX (UI/UX Specification)

> สถานะ: Phase 0 — ร่างเพื่อตรวจรับ
> ภาพหน้าจอตัวอย่าง: `08_WIREFRAMES/` · ตัวอย่างเอกสาร A4: `09_DOCUMENT_TEMPLATES/`

## 1. หลักการออกแบบ

| หลักการ | ทำอย่างไร | ไม่ทำ |
|---|---|---|
| เครื่องมือทำงาน ไม่ใช่หน้าโฆษณา | หน้าแรกคืองานที่ต้องทำวันนี้ (ค้างรับเงิน, เกินกำหนด, ร่างค้าง) | ไม่มี hero banner, ภาพประกอบ, คำทักทายยาว |
| อ่านตัวเลขง่าย | ตัวเลขชิดขวา, `tabular-nums`, คั่นหลักพัน, ทศนิยม 2 ตำแหน่งเสมอ, หน่วย "บาท" ไม่ซ้ำทุกช่อง | ไม่ย่อ "15.5K" ในจุดที่ต้องใช้ยอดจริง |
| สงบ เป็นมืออาชีพ | พื้นขาว/เทาอ่อน, สีหลักสีเดียว (น้ำเงินหมึก), สีมีความหมายใช้เฉพาะสถานะ | ไม่ใช้ gradient, เงาหนา, glassmorphism, emoji, ไอคอนตกแต่งที่ไม่สื่อความหมาย |
| ลดขั้นตอน | สร้างต่อจากเอกสารเดิมด้วยปุ่มเดียว, ค้นหาแบบพิมพ์บางส่วน, ค่าเริ่มต้นฉลาด (ราคาล่าสุด, เครดิตเทอมลูกค้า) | ไม่ถามซ้ำสิ่งที่ระบบรู้แล้ว |
| ป้องกันความผิดพลาดที่แก้ไม่ได้ | การออกเอกสาร/ยกเลิก มีหน้าสรุปก่อนยืนยัน และบอกผลที่ตามมาชัดเจน | ไม่ใช้ popup "แน่ใจหรือไม่?" ที่ไม่บอกอะไร |
| สิ่งที่เห็น = สิ่งที่พิมพ์ | Preview ใช้แม่แบบเดียวกับ PDF | ไม่มีหน้าจอสรุปยอดที่คำนวณต่างจาก PDF |
| ภาษาไทยเป็นหลัก | ข้อความไทยกระชับ ศัพท์สม่ำเสมอ (§10) | ไม่ปนอังกฤษโดยไม่จำเป็น (ยกเว้นเลขที่เอกสาร/รหัส) |

## 4. Component หลัก

| Component | พฤติกรรมสำคัญ |
|---|---|
| ปุ่ม | หลัก (พื้น brand), รอง (ขอบ), อันตราย (ขอบแดง — ไม่ใช้พื้นแดงเต็มเพื่อลดการกดพลาด), ปุ่มที่กำลังทำงานแสดง spinner และกดซ้ำไม่ได้ |
| ช่องเงิน | ชิดขวา, พิมพ์ตัวเลขอย่างเดียว, จัดรูปเมื่อออกจากช่อง (1250 → 1,250.00), ไม่ยอมรับค่าติดลบ |
| ช่องวันที่ | แสดงแบบไทย "10 พ.ย. 2569", เลือกจากปฏิทิน หรือพิมพ์ `10/11/2569` / `10/11/2026` ได้ (ตรวจปีอัตโนมัติ), มีปุ่ม "วันนี้" |
| ค้นหาลูกค้า (combobox) | พิมพ์ 1 ตัวอักษรเริ่มค้น; แสดงชื่อ + เลขผู้เสียภาษี + สาขา; ท้ายรายการมี "+ เพิ่มลูกค้าใหม่ '…'" |
| ค้นหาสินค้าในบรรทัด | พิมพ์ชื่อ/รหัส; ผลแสดงหน่วย + ป้ายราคาล่าสุด "ขายลูกค้านี้ 18.50 · 10 พ.ย. 69"; ไม่พบ → "บันทึกเป็นสินค้าใหม่" / "ใช้เฉพาะเอกสารนี้" |
| ตารางรายการสินค้า | Enter ไปบรรทัดถัดไป, ลากเพื่อเรียงลำดับ, ลบบรรทัด (มีปุ่มย้อนกลับ 5 วินาที), ส่วนลดรายบรรทัดซ่อนเป็นคอลัมน์ที่เปิดได้ |
| Badge สถานะ | ข้อความ + สี ตาม BR-ST-01; เกินกำหนดแสดงจำนวนวัน "เกินกำหนด 12 วัน" |
| สายเอกสาร (Document chain) | แถบแนวนอน QT → DN → INV → RC พร้อมเลขที่/สถานะ คลิกไปแต่ละใบได้ |
| Dialog ยืนยันการกระทำที่ย้อนไม่ได้ | หัวข้อบอกการกระทำ ("ออกใบกำกับภาษี INV-2026-0043"), รายการผลที่ตามมา, ปุ่มยืนยันระบุการกระทำ ("ออกเอกสาร") ไม่ใช่ "ตกลง" |
| Toast | สำเร็จ/ข้อมูล หายเอง 4 วินาที; ข้อผิดพลาดค้างจนปิด |
| Empty state | บอกว่าทำอะไรได้ + ปุ่มเดียว ("ยังไม่มีลูกค้า — เพิ่มลูกค้ารายแรก") |

## 5. ข้อกำหนดรายหน้าจอ

### S-01 เข้าสู่ระบบ
อีเมล + รหัสผ่าน (+ รหัส MFA ถ้าเปิด — D-10) · ข้อความผิดพลาดไม่บอกว่าผิดช่องไหน (กันเดาบัญชี) · ล็อกชั่วคราวหลังผิดติดกัน (`11_SECURITY_BACKUP.md`) · ไม่มีปุ่มสมัครสมาชิก (FR-AUTH-03)

### S-02 Dashboard
| ส่วน | เนื้อหา | ข้อกำหนด |
|---|---|---|
| แถวตัวเลข (4 ช่อง) | ยอดขายเดือนนี้ (ก่อน VAT) · ยอดรับชำระเดือนนี้ · ยอดค้างชำระรวม · เกินกำหนด (ยอด + จำนวนใบ) | FR-DSH-01, 03, 04, 07 |
| แถวที่ 2 | ยอดขายสะสมตั้งแต่ต้นปี + กราฟแท่งรายเดือน 12 เดือน (เส้นเทียบปีก่อนเป็นทางเลือก) · เอกสารที่ออกเดือนนี้แยกประเภท | FR-DSH-02, 05 |
| รายการงาน | รอรับเงิน (เรียงตามวันครบกำหนด) · เกินกำหนด · ใบส่งของที่ยังไม่ออกใบกำกับภาษี · ฉบับร่างค้าง · สถานะสำรองข้อมูลล่าสุด | FR-DSH-06, 07, 08 |
| การกระทำด่วน | ปุ่ม "รับชำระ" ในแต่ละแถวที่ค้าง | BR-PAY-10 |
| เกณฑ์ตัวเลข | ทุกตัวเลขมีข้อความเล็กบอกเกณฑ์ เช่น "ตามวันที่ใบกำกับภาษี ไม่รวม VAT" | BR-RPT-08, FR-RPT-11 |

### S-03 เริ่มสร้างเอกสาร
เลือก 1 ใน 4 ประเภท (การ์ดเรียบ ๆ มีคำอธิบายสั้น) **หรือ** ค้นหาเอกสารต้นทาง → แสดงประเภทปลายทางที่สร้างได้ตาม BR-DOC-07 · มีทางลัด "ขายเงินสด (ใบกำกับภาษี + ใบเสร็จ)" · ถ้าต้นทางมีปลายทางอยู่แล้ว แสดงคำเตือนตาม BR-DOC-09 ก่อนเข้าหน้าแก้ไข

### S-04 จัดทำเอกสาร (Document Editor) — หน้าจอหลัก
เลย์เอาต์ desktop: ซ้าย 60% ฟอร์ม, ขวา 40% Preview A4 (ย่อขนาด, เลื่อนตาม) — ปิด Preview ได้เพื่อขยายฟอร์ม

| ส่วน (ตาม PART 8) | ช่อง/การทำงาน | กฎ |
|---|---|---|
| Document Information | ประเภท (ล็อกหลังสร้าง), เลขที่ ("ออกเมื่อกดออกเอกสาร"), วันที่, สาขาที่ออก, วันยืนราคา (QT) / วันส่งของ (DN) / วันครบกำหนด (INV), เลขอ้างอิงลูกค้า | BR-NUM-01, BR-DATE-* |
| Customer Information | ค้นหาลูกค้า → เติมชื่อ, ที่อยู่, เลขผู้เสียภาษี, สาขา (แก้ได้เฉพาะเอกสารนี้), ผู้ติดต่อ; ป้าย "จด VAT" | BR-SNP-02, BR-CU-02 |
| Product Items | ตารางรายการ: สินค้า/รายละเอียด, จำนวน, หน่วย, ราคาต่อหน่วย, ส่วนลด, ประเภทภาษี (ซ่อนถ้าทุกบรรทัดเป็น VAT ปกติ), ยอด | FR-PR-*, BR-PR-03 |
| Discount | ส่วนลดท้ายเอกสาร (% หรือ บาท) | TR-04 |
| Tax Calculation | สลับ "ราคาไม่รวม VAT / ราคารวม VAT"; แสดงรวม, ส่วนลด, มูลค่าก่อนภาษี, ยอดยกเว้น (ถ้ามี), VAT 7% | TR-01…TR-09 |
| Grand Total | ยอดสุทธิตัวใหญ่ + จำนวนเงินตัวอักษร | TR-12 |
| Payment Information | เงื่อนไขชำระ, เครดิตเทอม → วันครบกำหนด, บัญชีธนาคารที่แสดง; INV: ตัวเลือก "รับชำระทันที" (ขายเงินสด) | BR-PAY-10 |
| Document Preview | แม่แบบเดียวกับ PDF + ลายน้ำ "ฉบับร่าง" | BR-DOC-01 |
| ปุ่มล่าง (ติดขอบล่าง) | **บันทึกร่าง** (รอง) · **ออกเอกสาร** (หลัก) · **พิมพ์ / PDF** (พิมพ์ร่างได้พร้อมลายน้ำ; หลังออกจะได้ฉบับจริง) | FR-DOC-07, 08 |

พฤติกรรม: บันทึกร่างอัตโนมัติทุก 10 วินาทีเมื่อมีการแก้ไข (แสดง "บันทึกแล้ว 10:42") · ออกจากหน้าโดยยังไม่บันทึก → เตือน · คำเตือน (เช่น วันที่ INV ≠ วันส่งของ) แสดงเป็นแถบเหลืองเหนือปุ่ม และต้องติ๊กยืนยันก่อนออก · ข้อผิดพลาดแสดงใต้ช่องนั้น ๆ และสรุปจำนวนที่ปุ่มออกเอกสาร
**Mobile:** ฟอร์มเป็นขั้นตอนพับได้ (ลูกค้า → รายการ → สรุป), Preview เปิดเป็นหน้าเต็มจากปุ่ม "ดูตัวอย่าง", ปุ่มออกเอกสารติดขอบล่าง

### S-05 รายการเอกสาร
ตัวกรอง: ประเภท (แท็บ: ทั้งหมด/QT/DN/INV/RC), สถานะ, ลูกค้า, ช่วงวันที่, ค้นหาเลขที่/ชื่อ/ยอด · คอลัมน์: เลขที่, วันที่, ลูกค้า, ยอดสุทธิ, คงเหลือ (INV), ครบกำหนด, สถานะ · เลือกหลายแถว → แถบการกระทำ "ออกที่เลือก" (เฉพาะร่าง) / "พิมพ์ / PDF รวม" (S-09) · Mobile: การ์ดรายการ 2 บรรทัด

### S-06 รายละเอียดเอกสาร
หัว: เลขที่ + badge สถานะ + การกระทำตามสถานะ (สร้างต่อเป็น…, รับชำระ, พิมพ์, ยกเลิก/ออกแทน, คัดลอกเป็นร่างใหม่) · สายเอกสาร (Document chain) · แท็บ: ตัวอย่างเอกสาร (PDF ต้นฉบับ) · การรับชำระ (INV: รายการรับเงิน, ยอดคงเหลือ) · ไฟล์ (ต้นฉบับ/สำเนา + sha256 ย่อ + ประวัติการพิมพ์) · ประวัติ (audit trail: เวลา, ผู้ทำ, เหตุการณ์, ค่าเดิม → ค่าใหม่, เหตุผล) · เอกสารยกเลิกแสดงแถบแดงด้านบน: ยกเลิกเมื่อ… เหตุผล… และลิงก์ฉบับแทน (ถ้ามี)

### S-07 ยกเลิก / ออกฉบับแทน (Dialog)
ขั้น 1 เลือกสาเหตุ (ตามรหัสใน `03_WORKFLOW.md` §10) — ระบบบอกเส้นทางที่ถูกต้องตามสาเหตุ (เช่น ราคาเปลี่ยนหลังขาย → แจ้งว่าต้องใช้ใบลดหนี้ ไม่ใช่การยกเลิก) · ขั้น 2 คำอธิบาย ≥ 10 ตัวอักษร · ขั้น 3 สรุปผลที่ตามมา (เลขเดิมคงอยู่, การรับชำระที่จะย้าย/ต้องกลับรายการ, ต้องเรียกคืนต้นฉบับ) · ปุ่มยืนยัน "ยกเลิก INV-2026-0042" / "สร้างฉบับแทน"

### S-08 รับชำระเงิน
ลูกค้า → รายการ INV ค้าง (ติ๊กเลือก, ยอดจัดสรรแก้ได้, ค่าเริ่มต้นใบเก่าสุดก่อน) · วันที่รับ, วิธี, บัญชีที่รับเข้า, เลขอ้างอิง · เงินที่ได้รับ + ภาษีหัก ณ ที่จ่าย (อัตรา/เลข 50 ทวิ) + ค่าธรรมเนียม = ยอดตัดหนี้ · แถบสรุป "จัดสรรแล้ว 20,000.00 / 20,000.00" ต้องเท่ากันจึงกดบันทึกได้ (BR-PAY-02) · ติ๊ก "ออกใบเสร็จทันที" (ค่าเริ่มต้นเปิด) · Mobile: หน้าเต็ม 1 คอลัมน์

### S-09 ออก/พิมพ์หลายเอกสาร (Mode B)
รายการที่เลือกเรียงตามลำดับที่จะออก/พิมพ์ (ลากเรียงได้) · แต่ละแถว: ประเภท, เลขที่ (หรือ "จะออกเลขเมื่อยืนยัน"), ลูกค้า, ยอด, ผลตรวจ (ผ่าน/คำเตือน/ไม่ผ่าน) · ตัวเลือก: ต้นฉบับ/สำเนา, PDF รวม หรือ ZIP แยกประเภท · ปุ่ม "ออก 3 ฉบับและสร้าง PDF" ใช้ได้เมื่อทุกแถวผ่าน (BR-BAT-01)

### S-10 ลูกค้า
รายการ (ค้นหา, กรองสถานะใช้งาน, ยอดค้างต่อราย) · รายละเอียด: ข้อมูลหลัก, สถานประกอบการ/สาขา, ผู้ติดต่อ, แท็บเอกสาร, แท็บยอดซื้อ/รับชำระ/ค้าง (ตัวเลข 12 เดือน) · ปุ่ม "สร้างเอกสารให้ลูกค้านี้"

### S-11 สินค้า
รายการ (รหัส, ชื่อ, หน่วย, ราคาล่าสุด, ใช้ล่าสุดเมื่อ, สถานะ) · แผงรายละเอียดด้านขวา: แก้ไขข้อมูล, ประวัติราคา (วันที่, เอกสาร, ลูกค้า, ราคา, รวม/ไม่รวม VAT), กราฟราคาแบบเส้นอย่างง่าย · ไม่มีช่องคงเหลือ

### S-12 รายงาน
เลือกรายงาน (9 รายการตาม FR-RPT-01…09) → ตัวกรอง (ช่วงวันที่, ลูกค้า, สินค้า) → ตารางผล + ยอดรวม → Export (Excel / CSV / PDF) · หัวรายงานแสดงเกณฑ์ เช่น "ยอดขายตามวันที่ใบกำกับภาษี ไม่รวม VAT ไม่รวมฉบับที่ยกเลิก" · รายงานภาษีขาย: เลือกเดือนภาษี, แสดงฉบับยกเลิก/ออกแทนพร้อมหมายเหตุ

### S-13 ตั้งค่า
แท็บ: ข้อมูลกิจการ (+ โลโก้, ผู้ลงนาม) · สาขา · บัญชีธนาคาร · เลขที่เอกสาร (รูปแบบต่อประเภท + ตัวอย่างเลขถัดไปแบบสด, โหมดปี — D-03) · ภาษี (ตารางอัตรา + เพิ่มช่วงใหม่, วันปิดงวดภาษี) · ค่าเริ่มต้นเอกสาร · บัญชีผู้ใช้ (รหัสผ่าน, MFA, ประวัติเข้าระบบ, ออกจากทุกอุปกรณ์) · สำรองข้อมูล (สถานะ, ผลทดสอบกู้คืนล่าสุด, ปุ่มดาวน์โหลดข้อมูลทั้งหมด)
การแก้ข้อมูลกิจการแสดงข้อความ "เอกสารที่ออกแล้วจะไม่เปลี่ยน มีผลกับเอกสารที่ออกหลังจากนี้" (FR-CO-07)

## 8. การเข้าถึง (Accessibility — WCAG 2.2 AA ส่วนหลัก)

คอนทราสต์ข้อความ ≥ 4.5:1 · ทุกช่องมี `<label>` · ใช้งานด้วยคีย์บอร์ดได้ทั้งหมด (focus ring ชัด 2 px) · ข้อผิดพลาดเชื่อมกับช่องด้วย `aria-describedby` · ตารางมี `<th scope>` · ข้อความเปลี่ยนสถานะประกาศผ่าน `aria-live` · พื้นที่แตะ ≥ 44×44 px บนมือถือ

## 9. การพิมพ์และ Preview

Preview และ PDF ใช้ HTML แม่แบบเดียวกัน (`09_DOCUMENT_TEMPLATES`) · ปุ่ม "พิมพ์" เปิด PDF ต้นฉบับที่เก็บไว้ (ไม่ render ใหม่) · ตัวเลือกพิมพ์: ต้นฉบับ / สำเนา / ทั้งคู่ · พิมพ์ต้นฉบับซ้ำ → ขอเหตุผล (BR-PRT-02)
